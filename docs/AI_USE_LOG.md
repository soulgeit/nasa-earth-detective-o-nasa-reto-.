# AI Use Log (SI) — submission requirement

The 2026 delivery guide requires stating where and how AI was used. Code and data
generated with AI are acknowledged in the descriptive text and in the metadata;
generated images and videos carry a visible watermark. This file is the basis of the
answer to the **«Use of Super Intelligence (SI)»** field of the submission form.

**How each item is marked**
- Code: the first line of every generated file → `SI-assisted: <agent> (<model>)` as a comment.
- Generated data (e.g. training questions): the `meta.source` field of each record and the
  `DATASET_CARD.md` sheet.
- NASA data: **not** generated; it carries `provenance` with the exact query.
- Images, video and audio: none is generated with AI unless noted here, and then with a visible label. Noted: the narration of `docs/demo/Huiracocha_AI_pitch_30s.mp4` is an AI-generated voice (ElevenLabs), labelled on screen. The project logo (`src/ui/assets/huiracocha_ia_*`, `favicon.png`) was generated with AI by the Antigravity agent; the app and the social-preview image carry a visible "AI-generated" mark.
